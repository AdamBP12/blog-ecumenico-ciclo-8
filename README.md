Blog del proyecto de transformación digital de Distribuidora Ecuménico, organizado en capítulos con el planteamiento, diagnóstico, trabajo de campo, objetivos y alternativas.

## Archivos del Proyecto
- `index.html`: Aplicación web editorial con selector lateral interactivo (sticky sidebar en desktop y drawer en móviles), galería de evidencias fotográficas de campo con modal lightbox, y los 6 capítulos integrados.
- `1.html`: Documento formal de Planteamiento del Proyecto (Información General, Diagnóstico, Problema General, Alineación Estratégica y Catálogo de Productos).
- `2.html`: Análisis del Entorno del Proyecto (EEFs, OPAs, Metodología de Levantamiento de Información en Campo con 3 Bloques de Entrevistas Estructuradas, Figuras 1-4 de evidencia forense y Tabla Comparativa AS-IS vs TO-BE).
- `3.html`: Gestión Estratégica de Interesados (Registro de Stakeholders, Matriz Poder/Interés, Cubo 3D, Modelo de Prominencia, Matriz RACI y Plan de Involucramiento).
- `4.html`: Marco Metodológico (Fases del Ciclo de Vida, Gestión Scrum por Sprints, Mapa de Historias de Usuario y Matriz de Priorización Valor vs. Esfuerzo).
- `5.html`: Ingeniería y Tecnología Propuesta (Diseño de Infraestructura Física, Arquitectura WMS, Flujo de Integración y Especificación de Casos de Uso UML).
- `6.html`: Control y Evaluación de Viabilidad (Análisis Financiero, Dashboard de KPIs, Matriz de Auditoría Audit Trail y Plan de Mitigación de Riesgos).
- `assets/images/`: Evidencias fotográficas de campo (notas de pedido manuales, almacenamiento a nivel de piso y mapa de rutas de reparto).
- `vercel.json`: Configuración de enrutamiento limpio para Vercel.
